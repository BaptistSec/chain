CHAIN CH19 (work in progress, builder-reported tests)

Keep ChainDemo.py, Play.bat and PlayText.bat together. Needs Python 3, standard library only.
Linux or macOS: python3 ChainDemo.py --menu
Windows: double-click Play.bat. Windows is untested.
Window: at least 104 columns by 48 rows.

GOAL: a run is three boards. On each board earn the credit quota (9, 10 and 10; one credit per target cleared) within 8 base shots (dock and heart bonus shots can add more). Aim the cannon, fire the ball, and clear yellow targets as it bounces through the pegs. Chains and rallies score more.

KEYS: left/right (or a/d) aim. Space or Enter fires. 1 to 4 choose the ball (normal, Rebound, Blast, Second Chance). p preview. f fast on/off. r restart. n next. q quits and prints your run code.
OVERDRIVE: a shot with a rally of x3 or more fills one of 3 meter segments. The third gives +1 Rebound ball for that board only, once per board; it does not carry over.

BOARDS: eight shapes (diamonds, waves, chevrons, arches, rings, spiral, funnel, stairs); the shape is named in the title bar.

JACKPOT: one target on each board is drawn as a star (or $$ in plain mode). Clearing it adds a flat +500 to that shot. It still counts as a normal target for the credit quota, so you never have to chase it.

DOCK: a catch zone sweeps along the floor. If the ball falls into it you get a free shot and +400. Only the first 2 catches on a board pay.

END OF A BOARD: the row under the board says how it went: "OUT OF SHOTS: N targets left to clear", or "Cleared in S shots, best rally xR, best chain C, Overdrive earned" (or "not earned"). Quitting prints your run code and one line per board.

DISPLAY: add these after the command, for example python3 ChainDemo.py --menu --mono
  --mono, or setting the NO_COLOR environment variable (to anything non-empty): no colour.
  --ascii: plain ASCII characters instead of block and box characters.
  --delay N: animation pause scale in milliseconds. The default is 30. 0 is the fastest setting. 10 takes about a third of the default time, 60 about twice as long.
  --text: one board as plain text with no colour codes. Type an aim from 1 to 39, then optionally r or x for a Rebound or Blast ball (for example 12 r). q quits. PlayText.bat runs this.

RUN CODES: the code printed on exit replays the run. Codes from older versions (CH18 and earlier) are rejected. Resume with --resume CODE.

NOT TESTED: a real Windows console, a person playing a full run, colour by eye.
